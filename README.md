# Mr. J's Math 8

Interactive math tools for Mathematics 8 — Elk Island Public Schools.

**Live site:** https://anjohnso-sys.github.io/mrj-math8/

Every tool is a single self-contained HTML file: no build step, no dependencies, and it keeps
working offline once the page has loaded. Designed for classroom projector display.

## Structure

```
index.html          course home page — one card per unit
unit1/ … unit10/    tools, named Unit{N}_{ShortName}.html
```

## Publishing

Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
